About the Project

Whats-On-Netflix turns a raw CSV into a living, interactive data product — combining backend analytics, REST APIs, and a Netflix-inspired frontend.

📊

What it does

Analyzes Netflix's global catalog across 8,800+ titles. Surfaces genre trends, country distributions, rating breakdowns, release patterns, and duration trends — all driven by a live Python/Flask API.

🔧

How it's built

Flask serves 12+ REST API endpoints. Pandas handles all data cleaning and aggregation. Plotly.js renders fully interactive charts in the browser. Everything is dynamically filtered — no static images.

🧠

Key technical decisions

API-first architecture separates data logic from presentation. Country data is properly cleaned (first country only, min. 10 titles). Charts respond to a global content-type filter in real time.

🔍

Search & Explore

Full-text search across titles, cast, directors, and descriptions. Multi-filter support: genre, type, rating, year range. Returns top 50 results with instant feedback.
